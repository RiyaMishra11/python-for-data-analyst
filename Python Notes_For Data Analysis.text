→← LECTURE -2 →←
COMPUTER MEMORY :- WHEN A PROGRAM RUNS COMPUTER STORES THEIR DATA INTO RAM(MEMORY) .

VARIABLE :- VARIABLE IS A NAME GIVEN TO A MEMORY LOCATION .

NOTE :- IN PROGRAMMING “ = ” MEANS ‘ASSIGNMENT OPERATOR’ i.e. LEFT VARIABLE STORE RIGHT VALUE .
EXAMPLE :- X = 10
THAT MEANS NOT X = 10 !!!
THAT MEANS STORE 10 INSIDE X .

VARIABLE NAMING RULES :- 
VARIABLE CAN START WITH ALPHABET.
IT CAN BE START WITH UNDERSCORE. 
VARIABLE CAN’T BE START FROM NUMBER.

SPECIAL CHARACTERS IS NOT ALLOWED IN VARIABLES.
SPACE IS ALSO NOT ALLOWED IN VARIABLE .
VARIABLE IS CASE SENSITIVE.

IDENTIFIRES :- IDENTIFIERS ARE THE NAMES USED TO IDENTIFY VARIABLES , FUNCTIONS , CLASSES ETC.

KEYWORDS :- KEYWORDS ARE RESERVED WORDS WE CAN’T MAKE THEM VARIABLES .
EXAMPLE :- IF , ELSE , ELSE IF , FOR , WHILE ETC .

LITERALS : - LITERAL MEANS ACTUAL VALUES .
EX - AGE = 20 | VARIABLE → AGE | LITERAL → 20

ISINSTANCE() :- THIS FUNCTION IS USED TO CHECK THAT THE GIVEN OBJECT’S TYPE IS PARTICULAR OR NOT .
EX- AGE = 20
PRINT(ISINSTANCE(AGE,INT))
OUTPUT :- TRUE


→← LECTURE -3 →← 
‘SEP’ PARAMETER -: MEANS SEPARATOR PARAMETER { “ ” }
EX - PRINT (“APPLE”, “BANANA” , “MANGO” , SEP= “-” )
OUTPUT - APPLE-BANANA-MANGO

‘END’ PARAMETER -: 
DEFAULT VALUE OF END IS → END=”\N”
BUT ,
WE CAN CHANGE IT , LIKE 
PRINT(“HELLO” , END= “ ”)
PRINT(“WORLD”)
OUTPUT : HELLO WORLD

ESCAPE CHARACTERS :- 
NEW LINE →
PRINT(“HELLO\nWORLD”)
OUTPUT :- HELL0 WORLD
TAB →
PRINT(“NAME\tAGE”)
OUTPUT :- NAME   AGE
DOUBLE QUOTE →
PRINT(“MY NAME IS \ “PRASHANT\””)
OUTPUT :- MY NAME IS “PRASHANT”
