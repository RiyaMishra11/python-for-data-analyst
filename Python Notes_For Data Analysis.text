PYTHON :- PYTHON IS A HIGH-LEVEL , INTERPRETED, GENERAL-PURPOSE PROGRAMMING LANGUAGE WHICH IS EASY TO READ AND UNDERSTAND .

CREATOR OF PYTHON :- GUIDO VAN ROSSUM
YEAR :- 1989
RELEASED :- 1991

“PYTHON” NAMED IS INSPIRED FROM ONE COMEDY TV SHOW “MONTY PYTHON’S FLYING CIRCUS” 

WHY PYTHON IS SO POPULAR :- 
BECAUSE OF , 1) EASY SYNTAX ,  2) HUGE COMMUNITY  ,
3) THOUSANDS OF LIBRARIES , 4) CROSS PLATFORM

COMPUTER MEMORY :- WHEN A PROGRAM RUNS COMPUTER STORES THEIR DATA INTO RAM(MEMORY) .

VARIABLE :- VARIABLE IS A NAME GIVEN TO A MEMORY LOCATION .

NOTE :- IN PROGRAMMING “ = ” MEANS ‘ASSIGNMENT OPERATOR’ i.e. LEFT VARIABLE STORE RIGHT VALUE .
EXAMPLE :- X = 10
THAT MEANS NOT X = 10 !!!
THAT MEANS STORE 10 INSIDE X .

VARIABLE NAMING RULES :- 
VARIABLE CAN START WITH ALPHABET.
IT CAN BE START WITH UNDERSCORE. 
VARIABLE CAN’T BE START FROM NUMBER.
